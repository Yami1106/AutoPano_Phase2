## About

An automatic **panorama stitching** system that aligns and blends multiple overlapping images into a seamless wide-angle panorama. Implements classical homography-based stitching alongside a deep learning approach.

---

## Features

- Feature detection (Harris corners / SIFT)
- Homography estimation with RANSAC
- Cylindrical and planar warping
- Multi-band blending for seamless panoramas
- Deep learning-based homography estimation (comparison)
